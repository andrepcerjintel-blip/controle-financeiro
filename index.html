IA NO SEU COMPUTADOR

Conexão privada.

Ollama executa um modelo local. Nenhum extrato ou pergunta é enviado a uma API na nuvem.

Verificando conexão…
Como ativar a IA local
  1. Instale o Ollama para Windows pelo site oficial, se permitido no computador.
  2. Baixe um modelo local no terminal: ollama pull qwen2.5:3b. O download inicial requer internet e espaço em disco.
  3. Mantenha o Ollama aberto, verifique a conexão e selecione “IA local”.

Esse modelo é um ponto de partida. Velocidade e qualidade dependem do computador. Use OLLAMA_NO_CLOUD=1 na configuração do Ollama para desativar recursos de nuvem e reinicie-o.

O painel aceita apenas modelos instalados sem indicação de execução em nuvem.
